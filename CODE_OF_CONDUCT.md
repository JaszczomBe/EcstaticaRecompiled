# Code of conduct

<!-- docs-tree:parent -->
[Project README](README.md)
<!-- /docs-tree:parent -->

Collaborate respectfully in project discussions, reviews, documentation and
technical investigations. Give people room to correct mistakes and explain
uncertainty. Critique code, evidence and decisions with specific reasons.

Harassment, threats, discriminatory remarks and sharing another person's private
information are unacceptable. Keep disagreements focused on the work and avoid
personal attacks. Respect the original creators' credit and the project's license.

If a concern needs attention, use an existing private channel to a repository
maintainer when available. Avoid publishing personal information in a public
report. Maintainers may moderate participation to protect constructive work.
